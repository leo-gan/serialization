# About

Serialization is an index for a set of GitHub repositories.

| Question | Section |
| --- | --- |
| Which repositories exist? | [Projects](projects/index.md) |
| Which repository implements a format? | [Formats](formats/index.md) |
| Where are the measurements? | [Benchmarks](benchmarks/index.md) |

The implementation repositories are standalone Mojo libraries. Their own documentation says how to install and run them. This site links to those repositories. It does not build them, and it does not copy their guides.

The benchmark covers 13 languages and many libraries that do not have a repository on this hub. The Mojo runner times the libraries that do.

Names, links, and the matrix cells are stored in one catalog. The site renders cards and fact sheets from that catalog at build time, so a URL or a package name is edited in one place.

The repositories are maintained by Leonid Ganeline and published under the [leo-gan](https://github.com/leo-gan) GitHub account.
